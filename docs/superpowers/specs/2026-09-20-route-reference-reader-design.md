# 路线技术资料全屏阅读层设计

## 背景

路线详情页右侧同时承载阶段上下文和完整技术文档。当前右栏约 340px，长文、代码、表格与 Mermaid 内容被限制在窄列内，阅读成本高，也容易与路线卡片争夺空间。

## 目标

- 右侧栏只承担阶段上下文和技术资料入口，不直接承载长文正文。
- 点击资料后打开全屏阅读层，正文拥有独立滚动区域。
- 桌面、平板、手机使用同一套阅读交互；手机自动使用单列全屏布局。
- 不改变卡片内容、路线进度、资料解锁和来源路径能力。

## 交互设计

1. 桌面端右侧栏展示当前阶段、资料数量、资料标题和用途摘要。
2. 点击某份资料后，打开覆盖整个窗口的阅读层；路线内容退出视觉层级，不再与正文并排挤压。
3. 阅读层顶部显示“小陈空间”来源、文档标题和关闭按钮。
4. 正文区域独立滚动，最大阅读列宽约 960px，保留代码块、表格和 Mermaid 的可读宽度。
5. 支持关闭按钮、遮罩点击和 Escape 键关闭；关闭后回到原路线滚动位置。
6. 平板和手机沿用全屏阅读层，不显示桌面右侧栏。

## 组件边界

- `RouteContextPanel`：阶段摘要与资料入口列表，不渲染完整文档正文。
- `RouteReferenceReader`：全屏阅读层，负责单份文档的标题、Markdown 正文、来源路径和关闭行为。
- `RouteDetail`：持有当前打开文档的 ID，负责打开/关闭以及阶段切换时清理无效选择。

## 样式约束

- 阅读层 `position: fixed; inset: 0`，使用页面纸张色背景，不暴露底层内容。
- 桌面正文列 `max-width: 960px`，左右边距使用流式值；手机使用 20px 内边距。
- 右侧栏保留 `top: 72px` 吸附安全距离，但只展示摘要入口。
- 阅读层代码块继续使用深色背景，正文、引用、表格和图示沿用现有 Markdown 样式。

## 验收

- 点击右侧资料可打开全屏阅读层，正文宽度不再受 340px 侧栏限制。
- 桌面端、平板端、手机端均无横向溢出和遮挡。
- Escape、关闭按钮和遮罩点击均可关闭，关闭后阶段和页面滚动位置不丢失。
- 正确/错误解锁、离线模式和已有路线进度测试不受影响。
